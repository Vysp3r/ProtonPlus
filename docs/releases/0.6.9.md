# ProtonPlus 0.6.9

## ✨ Features

- Refined the Tools, Games, preferences, and welcome interfaces, and added an in-app Help guide
- Grouped all tool categories on one launcher page and added direct compatibility version selection when editing one Steam game
- Added automatic retries and persistent resume for downloads, plus an optional HTTPS mirror for GitHub release assets
- Added native Linux packages and SHA-256 checksums to GitHub Releases
- Added Proton-Autogen as a launcher for managing Proton builds and game profiles
- Added Games tab libraries, Play, and folder actions for Lutris, Faugus Launcher, Heroic Games Launcher, and Bottles, with per-game runner editing for eligible Lutris and Faugus entries
- Added TinkerGame installation, updates, and copying of SteamTinkerLaunch settings
- Added warnings for incomplete Steam compatibility tools and a recovery guide
- Added Rosemary for macOS Steam games on x86-64 native and Flatpak Steam
- Improved the downloads popover and remaining-time display
- Added build selection for DXVK-Sarek releases with multiple archives
- Added Proton-Anime and Proton-HEVC behind the Show Niche Tools setting
- Improved CLI listings with stable tool IDs and installed release tags
- Added `search` and `outdated` with JSON output, plus `sync` and `cleanup` for the cache

## 🐛 Fixes

- Hardened tool installation, updates, and removal against overlapping operations, cancellation, and failed replacements
- Preserved Latest installations across provider renames and handled symlinked tool directories during updates
- Fixed Steam games not loading when Steam stores libraryfolders.vdf in the config directory
- Improved pending Steam changes and restart tracking, including persistence across ProtonPlus restarts and clearer failure messages
- Fixed Steam game launch IDs and opened the custom executable picker in the selected prefix's C drive
- Corrected provider metadata and release asset matching, and fixed DLSS updates being blocked by legacy NVAPI checks
- Fixed optional Flatpak components not being detected when multiple branches are installed
- Corrected launch-option descriptions and validation for RADV, ACO, and VKD3D flags
- Fixed custom launch wrappers appearing after Steam’s `%command%` placeholder

## 🔄 Changes

- Updated the Flatpak runtime to GNOME 51
- Removed the built-in MangoHud configuration editor; existing configurations and overlay launch options remain supported

## 🌐 Translations

- Refreshed translation catalogs and improved translations and plural labels

TinkerGame requires native ProtonPlus and native Steam outside SteamOS. Existing SteamTinkerLaunch installations remain supported and are not converted automatically.
