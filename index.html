Install GitHub Releases Documentation

Features

Compatibility tools

Install and update Proton, Wine, DXVK, and VKD3D for supported launchers.

Steam games

Change compatibility tools and launch options for one game or several at once.

Game libraries

Browse and launch games from Lutris, Faugus Launcher, Heroic Games Launcher, and Bottles. Edit per-game runners in Lutris and Faugus.

Gamepad and terminal

Navigate with a gamepad or use the command line to find runners, check for updates, and manage tools.

Meta Package Manager integrates with the ProtonPlus CLI to manage compatibility tools.

Supported launchers
  • Steam — System, Flatpak, Snap
  • Proton-Autogen — System profiles
  • Faugus Launcher — System, Flatpak
  • Lutris — System, Flatpak
  • Heroic Games Launcher — System, Flatpak
  • Bottles — System, Flatpak

Installation

Flathub is the recommended way to install ProtonPlus on x86-64 or ARM64.

Or install from the terminal.

flatpak install flathub com.vysp3r.ProtonPlus

GitHub Release Packages

Download an AppImage for x86-64 or ARM64 from GitHub. Starting with v0.6.9, GitHub releases also include native packages for Debian 13, Ubuntu 26.04 LTS, Fedora 45, and Arch Linux, plus SHA-256 checksums.

What's New in v0.6.9

Downloads and Packages

  • Automatically retry interrupted downloads and resume them after restarting ProtonPlus
  • Set an optional HTTPS mirror for GitHub release downloads
  • v0.6.9 adds native Linux packages and SHA-256 checksums to GitHub Releases

New Launcher and Tools

  • Manage Proton builds and game profiles with Proton-Autogen
  • Install TinkerGame with native ProtonPlus and native Steam outside SteamOS
  • Run macOS games with Rosemary on x86-64 native and Flatpak Steam

Game Libraries

  • Browse and launch games from Lutris, Faugus Launcher, Heroic Games Launcher, and Bottles
  • Change runners for supported Lutris and Faugus games
  • Choose a compatibility tool version when editing a single Steam game

Interface and Tool Management

  • Browse all tool categories on one page per launcher
  • See warnings and recovery steps for incomplete Steam compatibility tools
  • Keep pending Steam changes across ProtonPlus restarts
  • New in-app Help guide
